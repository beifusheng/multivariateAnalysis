# ⚠️ R 安装重要说明

## 问题说明

你使用 7-Zip 直接解压 `R-4.6.1-win.exe` 得到的**不是真正的 R 文件**，而是安装程序的内部结构。

R 安装程序是用 **Inno Setup** 打包的，不能直接用 7-Zip 解压出可用文件。

---

## ✅ 正确的安装方法

### 方法 1：运行安装程序（推荐）⭐

**步骤：**

1. **双击运行**：
   ```
   C:\Users\uf107146\Downloads\R-4.6.1-win.exe
   ```

2. **在安装向导中**：
   - 选择语言 → 确定
   - Next → I Accept → Next
   - **关键**：安装路径改为：
     ```
     C:\Custom\CodeRepository\Demo\electron-egg\r-portable
     ```
   - Next → Install
   - 等待安装完成

3. **验证安装**：
   打开新的命令提示符，运行：
   ```bash
   r-portable\bin\Rscript.exe --version
   ```
   
   应该显示：
   ```
   Rscript 4.6.1 (2026-04-15) ...
   ```

---

### 方法 2：使用自动安装脚本

**步骤：**

1. **运行脚本**：
   ```powershell
   cd C:\Custom\CodeRepository\Demo\electron-egg\r-scripts
   powershell -ExecutionPolicy Bypass -File install-r-portable.ps1
   ```

2. **按提示操作**：
   - 脚本会自动找到你的 R 安装程序
   - 启动安装向导
   - 指导你完成安装

3. **配置 PATH**（可选）：
   - 脚本会询问是否添加到用户 PATH
   - 选择 Y 添加到用户环境变量

## 📁 正确的目录结构

安装完成后，`r-portable` 目录应该是这样的：

```
r-portable/
├── bin/
│   ├── R.exe              ← R 主程序
│   ├── Rscript.exe        ← R 脚本执行器
│   ├── x64/
│   └── i386/
├── library/
│   ├── base/
│   ├── stats/
│   ├── utils/
│   └── ...
├── share/
│   ├── locale/
│   └── ...
├── etc/
│   ├── Rprofile.site
│   └── ...
└── include/
```

**关键文件**：`bin\Rscript.exe` 必须存在！

## 📦 关于 R 4.6.1

⚠️ **注意**：R 4.6.1 是未来版本（当前最新稳定版是 4.3.x）

如果你下载的是测试版或开发版，可能会遇到兼容性问题。

**推荐下载稳定版**：
- 访问：https://cran.r-project.org/bin/windows/base/
- 下载页面显示的最新稳定版（目前应该是 4.3.x）

## ✅ 安装完成后的下一步

1. **验证 R**：
   ```bash
   r-portable\bin\Rscript.exe --version
   ```

2. **安装 R 包**：
   ```r
   # 在 PowerShell 中运行
   & "r-portable\bin\Rscript.exe" "r-scripts\install-packages.R"
   ```
   
   或手动安装：
   ```r
   install.packages(c("jsonlite", "vegan", "glmnet", "Matrix"))
   ```

3. **启动应用**：
   ```bash
   npm run dev
   ```

4. **在应用中检查 R 环境**：
   - 点击"检查 R 环境"按钮
   - 应显示"✅ Portable R environment is ready"

## 🆘 需要帮助？

如果安装过程中遇到问题：

1. 确认安装路径没有空格或特殊字符
2. 确认有足够的磁盘空间（至少 500MB）
3. 查看安装日志（如果有）
4. 尝试重新下载安装程序

---

## 📞 总结

**不要**：
- ❌ 用 7-Zip 直接解压 R 安装程序
- ❌ 安装到需要管理员权限的目录（如 Program Files）

**要**：
- ✅ 运行安装程序
- ✅ 安装到用户目录或项目目录
- ✅ 使用自定义路径：`electron-egg\r-portable`
