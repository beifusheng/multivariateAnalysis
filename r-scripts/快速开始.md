# 🚀 便携版 R 快速开始（无需管理员权限）

## 三种方案，选择最适合你的

---

## ✅ 方案 A：最简单 - 应用自动检测

**适合：** 想要最简单体验的用户

### 步骤：

1. **下载 R**
   - https://cran.r-project.org/bin/windows/base/
   - 下载 `R-4.x.x-win.exe`

2. **解压到项目目录**
   ```
   electron-egg/
   └── r-portable/     ← 解压到这里
       ├── bin/
       │   ├── R.exe
       │   └── Rscript.exe
       └── ...
   ```
   
   **解压工具：** 使用 7-Zip 右键 → 7-Zip → 提取到此处

3. **启动应用**
   - 应用会自动检测 `r-portable/` 目录
   - 无需配置 PATH
   - 无需重启

### ✅ 优点：
- 最简单，零配置
- 应用启动即用
- 可放在 U 盘随身携带

### ⚠️ 注意：
- R 包会安装到用户目录（`%APPDATA%\R\`）
- 首次使用需要安装 R 包

---

## ✅ 方案 B：最灵活 - 用户环境变量

**适合：** 希望在任何地方都能使用 R 的用户

### 步骤：

1. **下载并解压 R**
   ```
   C:\Users\你的用户名\R-Portable\
   ```

2. **运行配置脚本**
   ```
   electron-egg/r-scripts/配置 R 路径.bat
   ```
   
   或手动运行 PowerShell：
   ```powershell
   cd electron-egg/r-scripts
   powershell -ExecutionPolicy Bypass -File configure-r-path.ps1
   ```

3. **重启终端/应用**

4. **验证**
   ```bash
   Rscript --version
   ```

### ✅ 优点：
- 任何地方都能用 R
- 命令行可直接调用
- 多个应用可共享

### ⚠️ 注意：
- 需要重启终端生效
- 仅修改用户环境变量（安全）

---

## ✅ 方案 C：最可控 - 应用内配置

**适合：** 高级用户，需要精确控制

### 步骤：

1. **解压 R 到任意位置**
   ```
   D:\MyApps\R-Portable\
   ```

2. **在应用中配置**
   - 打开应用
   - 点击"配置 R 路径"
   - 选择 `R-Portable\bin\Rscript.exe`

3. **完成**

### ✅ 优点：
- 完全手动控制
- 可随时切换 R 版本
- 适合多版本管理

### ⚠️ 注意：
- 需要应用支持配置界面
- 每个应用需单独配置

## 📦 R 包安装（三种方案通用）

### 方法 1：一键安装脚本

在项目中运行：
```bash
# Windows
cd r-scripts
Rscript install-packages.R

# 或在应用内点击"安装 R 包"按钮
```

### 方法 2：手动安装

打开 R 或 Rscript：
```r
# 安装基础包
install.packages(c("jsonlite", "vegan", "glmnet", "Matrix"))

# 安装 PERMANOVA-med
install.packages("devtools")
devtools::install_github("yijuanhu/LDM")
```

### 方法 3：使用应用

在应用界面：
1. 点击"检查 R 环境"
2. 如果包缺失，点击"安装必需包"
3. 等待安装完成

## 🔧 故障排除

### ❌ "找不到 Rscript"

**解决：**
1. 确认路径正确：`X:\...\R-Portable\bin\Rscript.exe` 存在
2. 如果是方案 A，检查 `r-portable/` 目录结构
3. 如果是方案 B，重启终端后验证 `Rscript --version`
4. 如果是方案 C，在应用中重新选择路径

### ❌ "包未安装"

**解决：**
```r
# 查看包安装位置
.libPaths()

# 手动安装包
install.packages("vegan")

# 如果权限错误，安装到用户目录
user_lib <- file.path(Sys.getenv("APPDATA"), "R", "win-library")
dir.create(user_lib, recursive = TRUE)
install.packages("vegan", lib = user_lib)
```

### ❌ "拒绝访问"

**原因：** 尝试写入需要管理员权限的目录

**解决：**
- 不要安装到 `C:\Program Files\`
- 使用用户目录或 D 盘
- R 包安装时指定 `lib` 参数到用户目录

### ❌ 应用检测不到 R

**解决：**
1. 检查目录结构是否正确
2. 查看应用日志中的搜索路径
3. 使用方案 C 手动配置路径
4. 运行配置脚本刷新 PATH
